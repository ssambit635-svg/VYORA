# Data directory

- `demo_samples/` — four **synthetic** 256×256 grayscale PNG scenes generated by `scripts/generate_demo_scenes.py`. Not real SAR, not georeferenced, not suitable for accuracy claims.
- `manifests/demo_scenes.json` — metadata and explicit synthetic warning for the gallery.
- `manifests/tiles.json` — **not included**. Add your own validated training/evaluation manifest here (see `docs/DATA_CARD.md`).
- `raw/` — gitignored location for licensed raw imagery. Do not commit restricted data.

Rebuild the demo set with:

```bash
.venv/bin/python scripts/generate_demo_scenes.py
```
