# Data card

## Bundled demo scenes (active)

Four deterministic 256×256 synthetic SAR-style grayscale illustrations live in `data/demo_samples/`. They are generated by `scripts/generate_demo_scenes.py`, have no geographic coverage, no VV/VH polarizations, no Sentinel source, and no optical targets. They are for UI smoke tests only and must never be used to train, validate, or claim model performance.

## Intended paired training source (not included)

The presentation proposes SEN12MS paired Sentinel-1/Sentinel-2 data. **No SEN12MS imagery or trained model is currently bundled or verified.** Before using it, document the exact release/record, access date, licence, scene groups, polarization order/units, target band order/scaling, cloud screening, acquisition dates and alignment checks. The slide's corpus count is a dataset citation, not a statement that those files are in this repository or ready for training.

### Preferred manifest

`ml.src.data.build_manifest` accepts JSON rows with:

| Field | Meaning |
|---|---|
| `tile_id` | Unique patch identifier |
| `scene_group` | Geographic/source scene ID; all its tiles remain in exactly one split |
| `split` | `train`, `validation` or `test` |
| `sar_vv_path` | VV single-band tile, calibrated/prepared first |
| `sar_vh_path` | VH single-band tile, on the same grid as VV |
| `optical_path` | Three visible target bands in R/G/B order; georeferenced GeoTIFF preferred |
| `optical_scale` | Optional target scale; default 10000 for integer-scaled Sentinel-2 reflectance, `1` for [0,1] values |
| `source`, `licence` | Provenance and reuse terms |

Legacy `sar_path` is accepted only for small synthetic smoke tests; it is duplicated as two channels and is not true dual-pol data. When all three inputs are GeoTIFF, the manifest validator checks dimensions, CRS and affine transform equality. This is an alignment guard, not a substitute for visual validation or temporal/cloud checks.

### Preprocessing and model contract

- GeoTIFF inference: two bands in the documented order VV then VH. Current service does per-band finite-value handling, 2nd–98th percentile scaling, 3×3 median filter, then 256×256 resize.
- **Radiometric calibration and terrain correction are not implemented by this code.** Prepare the Sentinel-1 product upstream (for example, the approved team workflow) and record exact steps. Do not label percentile normalization as calibration.
- Optical targets must be cloud-screened, co-registered, visible R/G/B order, and use an explicit scale. Preserve validation/test by geographical scene groups to reduce leakage.
- The output PNG/GeoTIFF is an estimated visual layer; optical targets are references, not universal “true colour” for the SAR acquisition.

Do not commit restricted raw imagery. Keep a small, legally distributable sample only if the source terms explicitly permit it. Store manifests at `data/manifests/tiles.json`; keep raw files outside Git.
